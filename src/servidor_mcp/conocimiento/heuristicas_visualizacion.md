# Heurísticas para visualizaciones

- Tarjetas: mostrar pocos indicadores principales con contexto y período.
- Líneas: representar tendencias sobre un eje temporal continuo.
- Barras: comparar categorías; son más legibles que un gráfico circular con muchas categorías.
- Dispersión: explorar relación entre dos medidas y descubrir valores atípicos.
- Tabla: presentar valores exactos o muchos atributos, no como reemplazo automático de un gráfico.
- Mantener colores y escalas consistentes. Reservar colores intensos para alertas o excepciones.
- Evitar ejes truncados cuando puedan exagerar diferencias y evitar efectos tridimensionales.
